# Start-up, login and session flow (traderappv1.open -> w_login1 -> w_main)

1. **Settings**: `af_get_app_setting()` loads server / database / company / security path (if missing: `f_set_client_info()` asks for them, else halt). `f_setlocalcomputername()`, `af_set_app_properties()` (application name, toolbar options, DataWindow message title "Waseela").
2. **Database health**: `f_get_database_status()` (< 0 -> halt).
3. **Single-instance control**: temporary connection `lt_multiple_session`; if table `configsetting` exists, setting `allow_multiple_session` (created with `'N'` when missing) decides whether a second copy on the same machine may run (`u_mutex.of_isrunning`; warning dialogs).
4. **Application session registry**: `u_session.of_createsession_setup()` registers this run; the application name becomes `Waseela (<session id>)`.
5. **Connect**: `sqlca` = OLE DB `SQLOLEDB`, `DATASOURCE = server`, `DataBase = db`, `APP/WSID` tagged with session id and computer name, autocommit off; then **first-time housekeeping**: `f_firsttime_script`, `f_firsttimewks_limit`, `f_firsttime_waytomoon`, `f_insert_client_instance`, `f_create_temp_directory`.
6. **Login**: `open(w_login1)` (`dw_password`: login/password; optional "remote" check box switches server/database from `dw_remote`); `cb_ok.clicked` -> `f_validatedw`, reconnect with the chosen server, `SELECT usercode, password FROM users WHERE username = :u AND Active = 'Y'`, case-insensitive password compare, three tries (`ii_tries`), `closewithreturn(w, 1)`. `message.doubleparm = 0` = cancelled -> halt.
7. **Licence**: `f_firsttimelic`, `f_islicenseexpire` (= -2 -> `w_activation`), session limits via `u_sessioninfo.of_createsession_setup` (return codes -2..-5 = single-user licence / DB problem / same user already logged in / max users reached), shell helper check (`cmdshell`), `w_logo` splash, `syscatelog` expiry flags (internal-error message if tampered/expired).
8. **Version / schema check**: `d_sequence` (`AppVersion`, `SequenceId`, `DBStatus`) vs `gl_appversion`: newer client than database -> upgrade by running the missing numbered scripts from `Script.mdb` (see ARCHITECTURE section 4) with automatic restore from the `...DBDump` device on failure; older client than database -> "update your application" halt; `DBStatus = 1` means a previous upgrade died -> offer restore.
9. **Caches**: `gds_preferences` (`d_general1`), `gds_colpref`, group category lists, item list `gd_itemsinfo` (+ alphabetic jump table `ga_llookuptable`, popup list, alias list), report headers (`d_CompReportHeaderInfo` -> `af_compheaders`).
10. **Shell**: `af_launch_startup_window()` (right 1118 -> `w_startup`), `af_launch_dashboard()`, `open(w_main)`; `w_main.open` sets the caption `WASEELA <app name> : <user> : <login time>`, loads `gds_security/gds_securitywindow`, applies menu security, starts the auto-refresh timer (`f_refreshitemlist` every N minutes from the user group's `autorefreshitemlisttime`).
11. **Logoff / exit**: `m_logoffadministrator` ("Change User") sets `ib_logoff`, closes `w_main`, re-opens `w_login`; closing asks "This will end your Application session" unless logging off; all sheets are closed first; session row is released (`u_session`).
