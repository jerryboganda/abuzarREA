# Abuzar project instructions

Read `CLAUDE.md` for repository boundaries and safety rules. For rebuild work,
read `rebuild\AGENTS.md`, including its **Project execution policy**.

The project policy is code-first: defer browser tests to one final consolidated
pass after the agreed implementation scope is complete; resolve routine choices
autonomously using recommended defaults rather than repeated questions.
Required approvals and truthful verification reporting still apply.

Never push this outer repository: its index contains vendor binaries. Do not
alter its existing index. The rebuild is a separate repository in `rebuild\`.
